Split-flap API

Version 1.0.0 · Portable browser renderer + optional HTTP transport

1. Embed the board

<div id="board" style="width:100%;max-width:1200px"></div>
<script src="visuals.js"></script>
<script src="core.js"></script>
<script src="board.js"></script>
<script>
  const board = new SplitFlapBoard(document.querySelector('#board'), {
    columns: 22,
    rows: 6,
    aspectRatio: 0.525,
    characterScale: 1.35,
    transition: {
      type: 'wave',
      direction: 'left-to-right',
      durationMs: 1800,
      sweepMs: 900
    }
  });

  const result = board.show({
    id: 'welcome-1',
    lines: ['  HELLO 🤖', '  準備完了']
  });
  if (result.accepted) {
    console.log(result.warnings);
    result.finished.then(console.log);
  } else {
    console.error(result.errors);
  }
</script>

No module loader is required. For a bundler, copy
these three browser assets into its public/static directory and load them in
order. SplitFlapBoard is exposed on window. core.js additionally supports require().
Use a dedicated host element that does not already have a shadow root.
The host width determines tile size; each tile preserves aspectRatio.

2. Methods and receipts

new SplitFlapBoard(hostElement, options = {})
  Creates a blank board. Invalid initial configuration throws TypeError.

board.show(message)
  Validates synchronously, then begins rendering. Returns one of:

  { accepted: true, id: 'welcome-1', warnings: [], finished: Promise }
  { accepted: false, errors: [{ code: 'INVALID_MESSAGE', message: '...' }] }

  finished resolves when the base message settles:
    { status: 'settled', id: 'welcome-1' }
  If interrupted before settling, it resolves with status:
    'superseded' | 'reconfigured' | 'destroyed'
  It never waits for infinite effects. Effects start as the base settles.
  Accepted receipts contain a Promise and are not themselves a wire protocol;
  the optional HTTP adapter returns a serializable acceptance receipt instead.

board.configure(patch)
  Merges a partial configuration (including a partial transition object).
  Returns { accepted: true, cleared: boolean, config: fullConfiguration }
  or { accepted: false, errors: [{code:'INVALID_CONFIG', message:'...'}] }.
  Invalid patches leave the board untouched.
  Successful configuration stops effects and any active message transition.
  A row/column change clears all cells. Other changes retain the base message,
  immediately settle it, and restyle it. Resend the message to restart effects.

board.clear(transition?)
  Equivalent to show({lines:[], transition}), filling every cell with blanks.
  With no transition argument it uses the board's default transition.
  Returns the same receipt as show(). Cancels all previous effects.

board.getState()
  Returns a detached snapshot:
    { config, id, base, visible, transitioning }
  base/visible are row-major arrays of {text, color}; color is null for text.
  visible tracks stable logical faces, not a composite image during a flip.
  transitioning refers to the base-message transition, not ongoing effects.

board.destroy()
  Stops animations/timers, resolves pending completion, disconnects resize
  observation, and empties the shadow root. Idempotent. Other methods throw
  after destruction. Use a fresh host element to create another board.

3. Board configuration

Defaults:
{
  "columns": 22,
  "rows": 6,
  "aspectRatio": 0.525,
  "characterScale": 1,
  "faceColor": "#2a2f37",
  "textColor": "#f0f0e9",
  "frameColor": null,
  "fontFamily": "\"Helvetica Neue\",Arial,sans-serif",
  "reducedMotion": "system",
  "transition": {
    "type": "wave",
    "direction": "left-to-right",
    "durationMs": 1800,
    "sweepMs": 900
  }
}

columns: integer 1–64; rows: integer 1–32; maximum 1024 cells total.
aspectRatio: width/height, 0.25–2. Tall reference: 0.525; squat study: 0.64.
characterScale: 0.25–2. Scales both text and emoji; oversized glyphs clip to faces.
faceColor/textColor: six-digit #RRGGBB. Blank cells use faceColor.
frameColor: #RRGGBB or null for the original gradient material.
fontFamily: a nonempty CSS font-family string. Fonts must be supplied by the host
or installed locally. Emoji retain the dedicated color-emoji fallback stack.
reducedMotion: 'system', true, or false. Reduced motion makes flips instant and
removes sweep delays. Timed ongoing effects still advance their frames.

The catalog checkboxes in catalog-study.html are demo-only controls. Any supported
text, emoji, or color can appear in an incoming message without enabling a catalog.

4. Message shape

{
  "id": "agent-status-42",
  "lines": [
    "  AGENT 🤖   ",
    "  準備完了    ",
    "            "
  ],
  "cells": [
    { "at": {"x": 0, "y": 0}, "value": {"color": "#2f9fff"} }
  ],
  "transition": {
    "type": "wave",
    "direction": "left-to-right",
    "durationMs": 1800,
    "sweepMs": 900
  },
  "effects": [
    {
      "at": {"x": 10, "y": 1},
      "frames": [" ", "▌"],
      "intervalMs": 700,
      "transition": {"type": "instant"}
    },
    {
      "at": {"x": 2, "y": 2},
      "frames": ["🤖", "🦞", "👾"],
      "intervalMs": 2000,
      "transition": {"type": "flip", "durationMs": 400}
    }
  ]
}

All top-level fields are optional. {} is a valid all-blank message.
id is an optional string for correlation; it does not deduplicate messages.
Omitted lines/cells/effects default to empty arrays. Omitted transition inherits
board defaults. An explicit transition is a partial override of those defaults.

Coordinates are zero-based: x is the column, y is the row, origin top-left.
The board is rebuilt logically from scratch for each message:
  blank grid → lines → cell overrides → ongoing effects.
This is a complete snapshot, not a partial update. Omitted positions become blank.

5. Whitespace, Unicode, and colors

Each lines entry occupies exactly one board row. No trim, centering, uppercasing,
word wrapping, or normalization is applied. Supply leading spaces for placement.
Explicit trailing spaces are honored; omitted trailing positions are also blank.
Additional rows and columns are truncated with warnings. Short rows and missing
rows are padded with spaces. Text after a row's width does not wrap to the next row.

A cell holds one Unicode grapheme cluster, using Intl.Segmenter:
  A, 界, é, 🤖, 👩‍💻, 🇯🇵 each occupy one cell.
CJK full-width typography still occupies one grid cell. Glyph availability and
emoji artwork depend on the viewing device's fonts. Glyphs that are too large
are clipped, so characterScale is a visual fitting control.

lines entries cannot contain tabs, CR, or LF. Convert multiline input explicitly:
  const lines = text.replace(/\r\n?/g, '\n').split('\n');
A newline starts the next row; the remaining cells in the prior row stay blank.

Each cells[].value and effects[].frames[] entry is either:
  "A"                     one grapheme
  " "                     blank charcoal face
  {"color":"#2f9fff"}     solid-color face, no glyph

Color faces retain the hinge, shadows, and texture. All other text faces return
to faceColor; colors do not leak from a prior screen. Emoji such as 🟦 are literal
emoji, not special color syntax. Empty string is not a valid single-cell value;
use a space. Colors accept #RRGGBB, not named colors or alpha.
Duplicate explicit cell overrides are rejected to avoid order-dependent placement.

6. Transition semantics

type: 'instant' | 'flip' | 'wave'
direction: 'left-to-right' | 'right-to-left' | 'top-to-bottom' | 'bottom-to-top'
durationMs: total base-message transition duration, 0–60000 milliseconds.
sweepMs: time from first axis position starting to last axis position starting.

instant ignores supplied timing and normalizes it to zero.
flip starts every changed cell together; sweepMs becomes zero.
wave requires 0 <= sweepMs < durationMs; durationMs must be positive.
For an N-column left-to-right wave:
  start delay = x / (N - 1) * sweepMs
  individual flip duration = durationMs - sweepMs
For a one-column horizontal wave, delay is zero and the flip uses full durationMs.
Vertical waves use rows in the same way. Unchanged cells stay still. The base
completion promise waits the configured total duration even if edge cells did
not change. Browser frame scheduling can add a small amount of latency; background
or throttled tabs are not real-time clocks.

This version uses one full old-face → new-face flip per changed cell. It does not
scramble through intermediate alphabet characters during a message transition.
Shading and rotation share the same timeline. Direction affects wave order only.

7. Ongoing effects

An effect sparsely overrides one cell after the base message settles. Every cell
may have an effect, but specifying only a few keeps the payload small. Duplicate
effect coordinates are rejected. Out-of-bounds coordinates generate warnings.

frames: 2–256 single-cell values.
intervalMs: 16–86400000; interval between frame starts, not extra dwell after a flip.
transition: optional; defaults to instant. Only instant/flip are supported here.
  A flip needs a positive durationMs <= intervalMs. No per-cell wave.
repeat: optional positive integer, maximum 1000000, counting complete frame cycles.
  Omitted means repeat until the message is replaced/cleared/reconfigured/destroyed.

Frame zero begins when the base settles. With frames [A,B], intervalMs 1000,
repeat 2: A starts at 0s, B at 1s, A at 2s, B at 3s; at 4s the effect restores
the underlying base cell using the effect transition. Independent effects have
independent timers and transitions. Animations are interrupted safely if a browser
is late processing a frame. A blink is represented by [" ","▌"]. A smoothly fading
opacity pulse is not a separate supported effect in v1.

A new valid message cancels all previous timers and animations. A half-flipped
cell snaps to its source or destination according to whether it passed the
midpoint, then transitions toward the new message. This avoids retaining torn
half-glyphs as a new stable state. Invalid messages do not cancel anything.
There is no queue, playlist, or message expiry in this version.

8. Validation and warnings

Validation finishes before the current display is changed. Unknown object keys,
invalid types, noninteger coordinates, negative coordinates, invalid colors,
invalid timings, and duplicate cell/effect targets reject the whole message.
Nonnegative integer coordinates outside the board are ignored with warnings.
Malformed out-of-bounds entries are still rejected; their values must be valid.

Warning codes:
  ROW_TRUNCATED       {y, received, rendered} — grapheme counts
  ROWS_TRUNCATED      {received, rendered} — row counts
  CELL_OUT_OF_BOUNDS  {at:{x,y}}
  EFFECT_OUT_OF_BOUNDS {at:{x,y}}

Example:
{
  "accepted": true,
  "id": "status-42",
  "warnings": [
    {"code":"ROW_TRUNCATED", "y":1, "received":24, "rendered":22}
  ]
}

9. Optional HTTP transport

Requires Node 20+. No npm install:
  node server.cjs

Default address: http://127.0.0.1:8787
Open /live.html for the connected display. Multiple open live displays receive
updates. /index.html is an independent editing playground, not a remote publisher.

Environment:
  HOST=127.0.0.1
  PORT=8787
  API_TOKEN=optional-secret

With API_TOKEN set, every /api request requires:
  Authorization: Bearer optional-secret
The live page has a token field; the token stays in page memory. Static files are
readable without it. Without API_TOKEN, API routes are unauthenticated. The server
binds only to loopback by default. Set HOST to the desired interface or place it
behind your application's proxy/Tailscale setup. This package does not configure
network access or TLS. CORS is not enabled; the live page is served on the same origin.

Routes:
  POST  /api/message   JSON message. Returns acceptance, id, warnings, connectedDisplays.
  PATCH /api/config    JSON configuration patch. Returns accepted, cleared, full config.
  POST  /api/clear     Clears all displays using configured default transition; no body.
  GET   /api/state     Current config, current message snapshot, connectedDisplays.
  GET   /api/events    SSE stream: snapshot, message, and config events.

Example:
  curl http://127.0.0.1:8787/api/message \
    -H 'Content-Type: application/json' \
    -d '{"id":"hello","lines":["  HELLO 🤖","  準備完了"]}'

For a configured token, add -H 'Authorization: Bearer your-token'.
Use --data-binary @message.json for larger messages so whitespace stays intact.

HTTP errors: 400 invalid JSON; 401 token failure; 413 body over 256 KiB;
422 invalid payload/configuration; 404 unknown API route/method.
A successful POST means the server accepted the payload and sent it to current
connections; it is not a renderer acknowledgment or proof the animation settled.
An accepted message with connectedDisplays:0 is retained for future connections.

The server is a single in-memory channel. Restarting resets its state. It sends
the current snapshot on connection; reconnecting replays the message and restarts
its effects. Separate displays do not share an exact animation clock. A config
change stops effects; reconnect snapshots reflect that stopped state.
Use your application's storage, identity, routing, and message delivery if you need
persistence or multiple named boards. An existing WebSocket client can simply do:
  socket.addEventListener('message', event => board.show(JSON.parse(event.data)));

10. Tests and portability

node --test core.test.cjs server.test.cjs
  Open browser-tests.html for renderer integration tests.

No build step, package registry dependencies, external assets, analytics, or
network calls in the renderer. Its only network activity is optional live.html
connecting to its same-origin HTTP adapter. Visual markup/CSS is isolated in a
shadow root. Use current browsers with Intl.Segmenter, Web Animations,
ResizeObserver, Shadow DOM, and CSS container units.
